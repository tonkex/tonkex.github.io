    추론의 기초: 질문이 답으로 바뀌기까지¶

    LLM에 질문을 보내면 어느 부분은 학습의 결과이고, 어느 부분은 지금 서버에서 수행하는 계산일까요? 이 영역은 모델이 사용자의 요청을 처리하는 과정을 처음부터 따라갑니다. 이 과정을 알면 응답 속도, 비용, 장비 선택에 관한 숫자를 더 정확히 읽을 수 있습니다.

    이 페이지는 Modular의 Foundations 소개를 한국어 독자의 읽기 경로로 확장했습니다. 기준 원고는 커밋 07e93d6입니다.

    1. LLM 추론이란 무엇인가 — 모델 계산과 서비스 운영을 구분합니다.
    2. 학습과 추론의 차이 — 가중치를 바꾸는 작업과 사용하는 작업을 비교합니다.
    3. LLM은 어떻게 답을 만드는가 — 토큰, attention, prefill, decode를 따라갑니다.
    4. LLM 추론은 어디에서 실행할까 — CPU·GPU·TPU와 배포 위치를 고릅니다.
    5. 추론 성능 지표 — 기다림과 처리량을 숫자로 설명합니다.

    이후 GPU 메모리, 배칭, PagedAttention으로 이어지면 여러 사용자의 요청이 한 서버에서 만날 때 생기는 문제를 이해할 수 있습니다.
