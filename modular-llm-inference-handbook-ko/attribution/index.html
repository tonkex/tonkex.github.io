    원문과 저작자 표시¶

    이 사이트는 Modular의 LLM Inference Handbook을 한국어로 번역하고 설명과 실습을 보탠 개작물입니다. 원문 저장소는 modular/llm-inference-handbook입니다.

    • 원문 저작자: Modular
    • 번역 기준 커밋: 07e93d6948c508b34bc7154a1400e025b0033ca3
    • 기준 확인일: 2026-11-11
    • 원문 docs/ 라이선스: CC BY 4.0
    • 한국어판 변경: 번역, 쉬운 설명, 지표 수식의 정의 보완, 절별 참고 자료, 별도 대화형 실습

    각 장 상단에는 해당 원문 페이지와 기준 시점을 연결합니다. 한국어판 보충 설명 표시는 원문에 없는 해설입니다. 새로 제작한 도해와 실습은 해당 페이지에서 별도로 설명합니다.

    원문 저장소의 코드·구성요소를 재사용하는 경우 그 파일의 Apache 2.0 조건과 NOTICE 유무를 따로 확인합니다. 제3자 이미지나 상표는 별도 권리 확인 뒤 사용합니다.
