    LLM 추론 핸드북 한국어판¶

    LLM API의 응답이 느리거나 GPU 비용이 높을 때, 어느 숫자부터 확인해야 할까요? 이 책은 Modular의 LLM Inference Handbook을 한국어로 읽을 수 있도록 옮기고, 필요한 배경 설명과 실습을 보탭니다.

    현재는 첫 6개 핵심 장을 읽을 수 있습니다. LLM 추론이란 무엇인가에서 요청 흐름을 살펴보고, LLM은 어떻게 답을 만드는가에서 토큰·prefill·decode를 읽은 뒤, 추론 성능 지표를 살펴보세요. 이어서 GPU 메모리 계산, 배칭, PagedAttention을 읽으면 여러 요청을 처리할 때 필요한 자원과 스케줄링을 연결할 수 있습니다. 원문의 나머지 문서는 영역별로 추가합니다.

    처음 읽는다면 용어집을 옆에 열어 두세요. 원저작자, 원문 기준 시점, 번역·보충 설명의 구분은 원문과 저작자 표시에 적었습니다.
