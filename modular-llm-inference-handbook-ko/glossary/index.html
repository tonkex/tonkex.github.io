    용어집¶

    용어 이 책에서 쓰는 뜻
    요청(request) 애플리케이션이 모델 서버에 보내는 입력과 생성 조건의 묶음
    토큰(token) 모델이 처리·생성하는 텍스트 단위. 단어와 항상 같지는 않다.
    추론(inference) 이미 학습된 모델을 이용해 입력에서 출력을 계산하는 과정
    서빙(serving) 요청 접수, 대기열, 추론 실행, 응답 전달을 포함한 서비스 운영
    TTFT 요청 후 첫 출력 토큰이 사용자에게 도착하기까지의 시간
    E2EL 요청 후 마지막 출력 토큰이 도착하기까지의 전체 시간
    TPOT 첫 토큰 이후 출력 토큰 사이의 평균 시간
    ITL 연속한 두 출력 토큰 사이의 실제 간격
    처리량(throughput) 일정 시간 동안 끝낸 요청 또는 처리한 토큰의 양
    Goodput 정한 성능 목표를 만족하며 끝낸 요청의 처리량
    SLO 서비스가 지키기로 정한 성능 목표. 예: TTFT 200 ms 이하
    가중치(weights) 학습으로 정해진 모델의 매개변수 값
    GPU 메모리(VRAM) GPU가 가중치, KV 캐시, 임시 계산 데이터 등을 보관하는 메모리
    KV 캐시 이미 처리한 토큰의 attention Key와 Value를 저장해 다음 토큰 생성에 재사용하는 공간
    Prefill 입력 토큰을 처리하고 첫 출력 토큰을 준비하는 단계
    Decode 이전 결과를 이용해 출력 토큰을 순서대로 생성하는 단계
    배칭(batching) 여러 요청을 하나의 GPU 작업 묶음에서 함께 처리하는 방식
    연속 배칭 토큰 생성 중 완료한 요청의 자리에 새 요청을 넣는 스케줄링 방식
    청크 단위 prefill 긴 입력을 여러 부분으로 나눠 처리하여 다른 요청의 decode를 사이에 배치할 수 있게 하는 방식
    PagedAttention KV 캐시를 블록 단위로 배치하고 조회표로 위치를 찾는 attention 및 메모리 관리 방식
    학습(training) 데이터와 목표를 이용해 모델의 가중치를 조정하는 과정
    파인튜닝(fine-tuning) 이미 학습된 모델의 가중치를 특정 작업이나 영역에 맞게 더 조정하는 학습
    손실(loss) 모델의 예측이 목표와 얼마나 다른지 나타내는 학습용 값
    역전파(backpropagation) 손실을 줄이기 위해 각 가중치를 어떻게 바꿀지 계산하는 과정
    CPU 범용 계산 장치. 작은 모델 추론과 요청 처리 등에 쓸 수 있다.
    GPU 많은 숫자 연산을 병렬로 실행하는 가속기. LLM 학습·서빙에 널리 쓰인다.
    TPU Google이 기계학습의 텐서 연산을 위해 설계한 가속기
    BYOC 외부 공급자의 소프트웨어를 사용자 자신의 클라우드 계정에서 실행하는 방식
    서버리스 추론 공급자가 모델 서버와 가속기 운영을 맡고 사용자가 API로 요청하는 방식
    자체 호스팅 모델 서빙 환경을 자신의 클라우드나 데이터센터에서 직접 구성·운영하는 방식
    기본 모델(base model) 주로 다음 토큰 예측으로 사전 학습한, 지시 수행용 후속 조정 이전의 모델
    지시형 모델(instruct model) 명령과 답변 예시로 조정해 사용자의 지시를 더 잘 따르게 한 모델
    MoE 여러 전문가 네트워크 중 일부를 토큰마다 선택해 계산하는 모델 구조
    샤드(shard) 큰 가중치 파일을 나눠 저장한 조각
    메모리 대역폭 GPU 메모리와 연산 장치 사이에서 단위 시간에 옮길 수 있는 데이터 양
    추론 프레임워크 모델 적재, 생성, 배칭, KV 캐시와 API 등 서빙 작업을 돕는 소프트웨어
    런타임 모델을 실제 장비에서 실행하는 소프트웨어. 제품에 따라 추론 프레임워크와 비슷한 뜻으로 쓰인다.
    제어 영역(control plane) 배포·확장·업데이트 정책을 관리하는 구성요소
    데이터 영역(data plane) 사용자의 요청을 받아 모델을 실행하고 응답을 보내는 경로
    온프레미스 조직이 직접 관리하는 장비에서 서비스를 실행하는 방식
